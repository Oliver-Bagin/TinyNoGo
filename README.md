Oliver Bagin, Parth 

## Requirments
Please follow the instructions `https://tinygo.org/` to install LLVM and WASM tools. All instructions for compiling tiny go from tinygo.org are applicible to this repo.  

To run our tests you will also need to `npm install` and have python3 with matplotlib.

## Examples/Tests
To run the example projects please run `node ./run.js`. This runs our pipline designed to investigate the properties of running application including the generating charts, debug logs ect.
